# 🧰 Ferramentas — o kit completo por etapa

Regra: **comece pelas grátis.** Só pague por uma ferramenta quando ela resolver um problema que você já tem.
Preços e planos mudam — confira no site oficial.

## Kit mínimo para a primeira venda (R$ 0)

| Função | Ferramenta grátis |
|---|---|
| Pesquisa | Biblioteca de Anúncios da Meta, Google Trends, YouTube |
| Criar conteúdo | Celular + CapCut + Canva |
| Rede social | Instagram (perfil profissional) |
| Conversar e vender | WhatsApp Business (app) + direct |
| Vender e entregar | Hotmart ou Kiwify (cobra só quando vende) |
| Calls / aulas ao vivo | Google Meet |
| Organização | Google Drive/Docs/Sheets, Notion ou Trello |
| IA assistente | ChatGPT, Claude ou Gemini (planos grátis) |
