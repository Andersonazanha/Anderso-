### Fórmulas (no Google Sheets)
```
CTR %     = Cliques ÷ Impressões × 100
CPC       = Investimento ÷ Cliques
Conversão da página % = Vendas ÷ Visitas × 100
Conversão do checkout % = Vendas ÷ Inícios de checkout × 100
CPA       = Investimento ÷ Vendas
ROAS      = Faturamento ÷ Investimento
Lucro     = Faturamento − taxas da plataforma − impostos − investimento
```

## 🚦 Painel diário do funil (Growth Engines)
Digite **à mão**, todo dia de manhã, os números de ontem. Pinte cada linha: 🟢 na meta · 🟡 perto · 🔴 longe.
**O pior 🔴 do dia é a única coisa em que você trabalha hoje.**

| Elo | Fórmula | Meta inicial* | Ontem | Cor |
|---|---|---|---|---|
| Hook rate | Reproduções de 3 s ÷ impressões | 30%+ (bom: 40–50%) | | |
| CTR (link) | Cliques no link ÷ impressões | 1%+ | | |
| Carregamento | Visualizações da página ÷ cliques | 70%+ | | |
| Página → checkout | Finalizações iniciadas ÷ visualizações | 10%+ | | |
| Checkout → compra | Compras ÷ finalizações iniciadas | 40%+ | | |
| Order bump | Compras do bump ÷ compras | 20%+ | | |
| Custo por compra | Investimento ÷ compras | ≤ CPA máximo | | |

\* Metas de partida para ajustar com os **seus** números depois de 2 semanas. Hook rate: referência citada por
Rodrigo Krueger (Scaling Secrets #182); as demais são pontos de partida do tutor.
