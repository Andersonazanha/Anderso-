# 📖 Glossário de marketing digital

| Termo | Significado |
|---|---|
| **Afiliado** | Quem vende produto de outra pessoa e ganha comissão |
| **Avatar / persona** | Retrato detalhado do cliente ideal |
| **Carrinho aberto** | Período em que as vendas estão abertas num lançamento |
| **Checkout** | Página de pagamento |
| **Copy / copywriting** | Texto persuasivo que leva à ação |
| **Coprodutor** | Sócio que divide o lucro de um produto (geralmente cuida do marketing) |
| **CPA** | Custo por aquisição (quanto custou cada venda) |
| **CPC** | Custo por clique |
| **CPL** | Custo por lead |
| **CPM** | Custo por mil impressões |
| **Criativo** | A peça do anúncio (vídeo, imagem, carrossel) |
| **CTA** | *Call to action* — chamada para ação ("clique", "comente", "compre") |
| **CTR** | Taxa de cliques (cliques ÷ impressões) |
| **Escada de valor** | Sequência de produtos do mais barato ao mais caro |
| **Funil** | Caminho do desconhecido até o cliente (atrair → nutrir → converter) |
| **GEO** | Otimização para aparecer nas respostas de IAs (ChatGPT, Gemini, Perplexity) |
| **Gancho** | Os primeiros segundos/frase que prendem a atenção |
| **High ticket / low ticket** | Produto caro / produto barato |
| **Infoproduto** | Produto digital de informação (curso, e-book, mentoria online) |
| **Isca digital / lead magnet** | Material grátis oferecido em troca de contato |
| **Lançamento** | Venda concentrada num período, com aquecimento antes |
| **Lançamento semente** | Primeiro lançamento, simples, muitas vezes antes de o produto estar gravado |
| **Lead** | Contato interessado (deixou e-mail/WhatsApp) |
| **LGPD** | Lei Geral de Proteção de Dados |
| **Order bump** | Oferta extra barata no checkout ("adicione também por R$ 27") |
| **Orgânico** | Alcance sem pagar anúncio |
| **Perpétuo** | Venda contínua, todos os dias, sem data de fechamento |
| **Pixel** | Código que rastreia ações do site para a plataforma de anúncios |
| **Prova social** | Depoimentos, resultados e números que mostram que funciona |
| **ROAS** | Retorno sobre investimento em anúncios (faturamento ÷ investimento) |
| **SEO** | Otimização para aparecer no Google |
| **Social selling** | Vender por meio de conversas nas redes sociais |
| **Tráfego pago** | Visitantes trazidos por anúncios |
| **Upsell** | Oferta de produto maior/mais caro depois da compra |
| **UTM** | Etiquetas no link para saber de onde veio o visitante |
| **Vitória rápida** | Primeiro resultado que o aluno alcança logo no início |
